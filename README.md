# 指示人狼 — 7人用プロトタイプ

## 1台で試す（動作確認用）
`public/index.html` をブラウザで開くだけ。画面上部のセレクトで7人を切り替えられます。

## 7台で本番プレイ（こちらが本命）
Node.js 18 以上が入ったPCで、**初回だけ**このフォルダの中で以下を実行してください（Wi-Fiが必要です）。

```
npm install
```

これで通知機能（プッシュ通知）の準備が整います。あとは毎回これだけです。

```
node server.js
```

起動時に表示される `http://192.168.x.x:3000` を、**同じWi-Fi / 同じテザリングにつながった7台のスマホ**で開きます。

1. 1人が「ゲームを作る」→ 7人の名前を入力 → 6桁コードが出る
2. 残り6人が「ゲームに参加する」→ コード入力 → 自分の名前を選ぶ
3. 各自が役職を確認 → 旅行スタート

`npm install` をしていなくても `node server.js` だけで全機能（通知以外）は動きます。通知は使わない場合、この手順は不要です。

PCを持っていかない場合は、`server.js` + `public/` を Render / Railway / Fly.io などに置けばURLだけで遊べます（Webサービスとして `npm install && node server.js` を実行するだけ、ビルド不要）。

## プッシュ通知について
ホーム画面の「🔔 通知を有効にする」を押すと、アプリを閉じていても指示や自動通知が届いたときに通知が来ます。差出人が誰かは通知の文面からは絶対に分かりません（人狼の指示も市民への自動通知も同じ文面です）。

iPhoneの場合、Safariの共有ボタン→「ホーム画面に追加」してから、そのアイコンで開いて通知を有効にしてください（iOSの制約で、ホーム画面に追加したアプリでしか通知を受け取れません）。Androidはそのままブラウザで有効にできます。

## 秘密ミッションについて
旅行全体で3つだけ、ランダムに選ばれた3人にランダムなタイミング（1個目は開始から30〜90分後、2個目・3個目はその前のミッションから3〜4時間後）で届きます。人狼か市民かは関係なく選ばれます。受け取った本人にだけ「🎯 SECRET MISSION」という専用の画面が表示されます。「MISSION CLEAR」を押すと、自分以外の6人からランダムに1人の役職を知ることができます。内容は `server.js` の `SECRET_MISSIONS` 配列で編集できます。

## 仕様メモ
- 指示の遅延は `server.js` の `MAX_DELAY_MS`（既定 5分）
- 市民向け自動通知の間隔は `topUp()` の `rnd(600, 2100)`（10〜35分）
- 自動通知の文面は `AMBIENT` 配列。方向性を教えてもらえれば書き換えます
- ゲームデータは `games.json` に保存されます
- 旅行ログには写真も添付できます（自動的に縮小・圧縮されます）
